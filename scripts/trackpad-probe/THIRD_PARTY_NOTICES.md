# Multitouch ABI reference

[OpenMultitouchSupport](https://github.com/Kyome22/OpenMultitouchSupport),
`Framework/OpenMultitouchSupportXCF/OpenMTInternal.h`, blob

No upstream binary or macOS 15-only package is linked.
